# Resource collection pages

The public catalog has focused landing pages for courses, videos, articles, certification study, serverless, security, generative AI, fundamentals, architecture, data, DevOps, YouTube channels, blogs, podcasts, newsletters, AWS User Groups, and Student Builder Groups. `src/lib/resource-collections.mjs` owns the routes, copy, selectors, route lookup, and compact learning-navigation links used by the pages and site integrations.

Each page filters the same published catalog by resource kind and its declared format or topic. The directory receives only the matching resources for its result list, search, filters, sorting, and resource hash links. It also receives the complete resource and event arrays so cards can resolve existing relationships such as creators, communities, and recordings. An empty match still renders the page guidance and route navigation.

`/aprender/` and every content collection page share compact links to **Todos los recursos**, **Cursos**, **Videos**, and **Artículos**, plus a native **Temas y objetivos** disclosure. Its real links include each existing thematic collection and the fundamentals, architecture, data, and DevOps destinations. The current destination uses `aria-current="page"`; a selected theme also appears in the closed disclosure label. The menu uses server-rendered HTML and an absolutely positioned panel, so it works without JavaScript and opening it does not move the results. With JavaScript, it closes when focus leaves the disclosure, on Escape, or on a click outside. Escape inside closes it and returns focus to its summary; Escape outside preserves the focused control. This learning navigation is separate from the existing creator, source, community, and event navigation callers.

The new `/aprender/fundamentos/`, `/aprender/arquitectura/`, `/aprender/datos/`, and `/aprender/devops/` pages select only content carrying their matching catalog topic. They have distinct page metadata, introductions, and guidance, and inherit their static route, canonical, sitemap, and search-index integration from the collection registry. The fundamentals page links to `/recorridos/primeros-pasos/`; its collection guidance does not imply that every listed item is for beginners. These pages describe the catalog's selected topics without claiming resources are free, certified, or current.

The generative-AI collection uses explicit wording or named AWS tools in a resource title, description, or URL: generative AI / IA generativa, Amazon Bedrock, Strands Agents, or AgentCore. The `Inteligencia Artificial` topic by itself does not qualify, which keeps general AI and machine-learning material out of that focused page.

The shared `ResourceCollection` component renders the content and creator collections from static route parameters. The two community collections have named pages. Directory breadcrumbs and named slots support the community country pages while keeping their existing defaults. Collection pages omit a facet only when that dimension is already fixed by the selector; other applicable facets stay available.

The initial resource order is the existing editorial recommendation order: featured records first, then `addedAt`, with original catalog order as the stable tiebreaker. The explicit directory sort restores the original order and the recent sort uses `addedAt`. Certification study defaults to a purpose grouping derived from each resource's public title and description. The title is checked first for an explicit exam name or supported code; the description is checked only when the title contains no recognized exam. Every resource has one visible group. Resources naming more than one recognized exam appear under “Varios exámenes,” and remain included when filtering any named exam they mention. The visible “Examen o tipo de recurso” control writes `?group=ID`; it is available only on this collection. On desktop, it shares a row and aligned control baseline with **Ordenar por**, above the additional-filters disclosure; on narrow screens, the controls stack. The result counter remains beside the results. Choosing directory, recent, or recommended returns a flat list with the corresponding sort order.

Search stays visible while secondary facets use native `details` and `summary`. The complete resource list and its links are present in server-rendered HTML. Selected collection pages render visible FAQ content from `collection.faq`; the same resolved FAQ items feed the site's search index and site verifier. The four thematic collections with existing learning paths link to them before the filter controls, with those links omitted from their after-results guides. The courses FAQ shows a concrete free-study example only while its currently published catalog course still points to the provider page that makes that claim. Without that record, it tells readers to check price and access conditions on the provider page. The example links through the published catalog card; it makes no claim about the price or availability of every course or exam. A separate course FAQ points to available level filters and does not assert duration or account requirements that are absent from the catalog.

These pages organize existing published records. They do not claim that a course is free, official, complete, current, or sufficient for certification unless its own published information supports that claim.
